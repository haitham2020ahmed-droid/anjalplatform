   RR-021, RR-043, RR-073, RR-129, RR-132, RR-138, RR-145,

   المحتوى نفسه لم يتغير في جوهره)

3) 3 ملفات كود/إعدادات معدّلة من قبل (موجودة أصلاً من جلسة سابقة):
   - data/readrise/FORMAT.md
   - scripts/readrise/check.mts
   - src/server/readrise/import.ts

كل المحتوى تمت كتابته من الصفر (أصلي بالكامل)، وتم فحصه بالكامل ليكون
مناسبًا لطلاب الصفوف 4-6 في السعودية، وخاليًا من أي شيء غير مناسب
(خمور، لحم خنزير، قمار، علاقات عاطفية، أعياد غير إسلامية، إلخ).

النتيجة النهائية: مكتبة ReadRise الآن فيها 450 مقال، كل واحد فيه 14 نسخة
بمستويات قراءة مختلفة (300 إلى 1600)، وكل المقالات نجحت في فحص الجودة
التلقائي (check.mts) بدون أي خطأ واحد.

خطوات التطبيق (بالترتيب):
---------------------------
1. افتح الـ Terminal وروح لمجلد المشروع عندك على جهازك.

2. تأكد إنك على فرع (branch) نظيف وما فيه تعديلات معلقة:
   git status

3. فك ضغط هذا الملف، وانسخ كل الملفات والمجلدات اللي بداخله
   (ابتداءً من مجلد data و scripts و src)
   إلى مجلد المشروع عندك، بحيث تحل محل أو تضاف بجانب الملفات
   الموجودة بنفس المسار. (فك الضغط فوق مجلد المشروع مباشرة هو الأسهل،
   لأن التراكيب (المسارات) متطابقة تمامًا.)

4. تحقق من التغييرات:
   git status
   (المفروض تشوف ~250 ملف جديد (untracked) و 14 ملف معدّل (modified))

5. شغّل فاحص الجودة على كل المكتبة للتأكيد (اختياري لكنه مفيد):
   npx tsx scripts/readrise/check.mts data/readrise/articles/RR-*.json

   لو حابب تشوف بس آخر النتيجة:
   npx tsx scripts/readrise/check.mts data/readrise/articles/RR-*.json | grep -c "✓"
   المفروض يطلع لك 450

6. شغّل الفحوصات العادية عندك (type-check / build) حسب طريقتك المعتادة:
   npm run typecheck
   npm run build

7. لو كل شي تمام، أضف الملفات وسجّل الـ commit وادفعها:
   git add data/readrise/articles data/readrise/FORMAT.md scripts/readrise/check.mts src/server/readrise/import.ts
   git commit -m "ReadRise: إضافة 250 مقال جديد (#281 إكمال + #282 فنون وجغرافيا + #283 قصص) وتصحيح 11 مقال قديم"
   git push

8. بعد النشر، شغّل أمر إعادة تحميل محتوى ReadRise في قاعدة البيانات
   (نفس الطريقة التي تستخدمها عادة بعد أي تحديث لمحتوى ReadRise - عادة db:seed أو أمر مشابه حسب إعدادك).

ملاحظة مهمة:
-------------
ما عدلت أي شيء في قاعدة البيانات (schema) - كل التغيير محتوى (JSON) فقط،
بالإضافة لتعديلات صغيرة سابقة في 3 ملفات كود كانت ضرورية لإضافة
"Arts & Culture" و"Geography" و"Fiction" كمواضيع صالحة ولإصلاح باقين بالفاحص
(check.mts) - وهذه التعديلات كانت موجودة من جلسة سابقة ولم تتغير الآن.

لو واجهت أي مشكلة أو ظهرت أي رسالة خطأ، ابعتها لي وأنا أحلها معك.
