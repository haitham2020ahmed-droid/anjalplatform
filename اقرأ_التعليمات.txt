تحديثين صغار (مش حل جذري — تنبيه + توضيح، لحد ما نعرف السبب الحقيقي بالظبط)
================================================================================

1) لما ترفع ملف NWEA وتجيلك رسالة "تم الاستيراد" بس المناطق فاضية
   --------------------------------------------------------------
   فحصت الكود ولقيت: درجة RIT/Percentile/Lexile العامة بتتسجل في خطوة،
   ودرجات المناطق الثلاثة (Informational/Literary/Vocabulary أو
   Grammar/Mechanics/Writing) بتتسجل في خطوة تانية منفصلة — وبتعتمد على
   إن كل منطقة ليها "كود" مسجل في جدول منهج المدرسة (MapGoalArea). لو
   الكود ده مش موجود لأي سبب، المنطقة دي كانت بتختفي بصمت من غير أي
   تحذير — يعني الاستيراد "ينجح" ظاهريًا بس المنطقة فعليًا ضايعة.

   دلوقتي: لو ده حصل، هتشوف تحذير واضح في رسالة الاستيراد نفسها بيقولك
   بالظبط أي منطقة (أو مناطق) ما اتسجلتش وليه. يعني في المرة الجاية اللي
   ترفع فيها أي ملف، لو المشكلة دي رجعت، ابعتلي "screenshot" من الرسالة
   اللي هتظهر — وهعرف أتصرف فورًا بالسبب الحقيقي بدل التخمين.

2) توضيح أنواع تقارير NWEA في صفحة رفع الملفات
   --------------------------------------------
   زي ما طلبت، دلوقتي تحت زرار الرفع هتلاقي 3 سطور صغيرة بتوضح أي تبويب
   من تقرير NWEA فيه إيه بالظبط:
   📘 Instructional Areas — فيها RIT + المناطق التلاتة ✅ الأفضل
   📈 ASG (Achievement Status and Growth) — نفس كده + توقع الربيع ✅
   📊 Test Details — RIT بس من غير تفصيل مناطق ℹ️ متحتاجش ترفعه

خطوات التطبيق
==============

1) افتح Terminal وروح لمجلد المشروع:

   git pull

2) فك ملف الـ zip ده في مجلد المشروع.

3) جرب الباتش قبل التطبيق (اختياري):

   git apply --check missing-areas-visibility.patch

4) طبّق الباتش:

   git apply missing-areas-visibility.patch

5) سجل ورفع:

   git add -A
   git commit -m "MAP import: surface instructional areas that couldn't be matched; label NWEA report tabs"
   git push

ملحوظة مهمة
============
بخصوص الملفات اللي بعتهالي (Class Profile لكل الفصول، وملفين Test
Details، وملف ASG رياضيات):
- ملفات الـ Class Profile (تبويب Instructional Areas) لكل الفصول (4A،
  4B، 5A، 5B، 6) جاهزة للرفع زي ما هي — ارفعها من صفحة كل فصل.
- ملفي Test Details متحتاجش ترفعهم، مفيهمش تفصيل مناطق أصلاً.
- ملف الرياضيات (Math ASG) مش هيتقرا، لأن المنصة شغالة على القراءة
  واللغة بس.

لو بعد كده المناطق لسه مش بتدخل حتى مع التحذير الجديد، ابعتلي نص
الرسالة اللي ظهرت بالظبط وهحدد السبب من جذوره.
