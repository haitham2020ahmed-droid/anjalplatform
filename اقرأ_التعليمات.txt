تحديث: صندوق رفع ملفات عادي في صفحة الاستيراد الجماعي
====================================================================

شو حصل: ضفت زر "اختر ملف" عادي في صفحة /admin/bulk-map-import، فبقى
تقدر ترفع ملفات NWEA بنفسك من المتصفح مباشرة، من غير Terminal ومن غير
ما تحتاج مني أعملك Patch في كل مرة.

إزاي تستخدمه (بعد ما تطبق هذا التحديث):
1) افتح https://anjalplatform-1.onrender.com/admin/bulk-map-import
2) تحت عنوان "📤 Upload PDF(s) to import now" اضغط "Choose File"
   واختار ملف أو أكتر (تقدر تختار أكتر من ملف PDF مرة واحدة).
3) اضغط "Import uploaded file(s)" وهياخدك نفس التقرير اللي بتشوفه
   عادي (كام طالب اتسجل، كام اسم مش موجود، إلخ).

الملف مش بيتسجل في GitHub ولا يتحفظ في أي مكان — بيتقرأ مرة واحدة
وينستورد، يعني تقدر تستخدمه براحتك أي وقت تحب من غير أي خطوة تقنية.

الملفات المعدّلة:
- src/app/admin/bulk-map-import/actions.ts  (دالة الاستيراد الجديدة)
- src/app/admin/bulk-map-import/page.tsx    (صندوق رفع الملف)

تم التحقق من أن الباتش يُطبَّق بنجاح 100% على نسخة طازجة من GitHub.

خطوات التطبيق:
------------------------------------------
1) ضع ملف الـzip هذا داخل مجلد المشروع (alanjal-adaptive-ela) مباشرة.
2) افتح Terminal في نفس المجلد ونفّذ الأمر التالي دفعة واحدة:

unzip -o upload-box.zip && git apply --check upload-box.patch && git apply upload-box.patch && git add src/app/admin/bulk-map-import/actions.ts src/app/admin/bulk-map-import/page.tsx && git commit -m "MAP: add a browser file-upload box to the bulk import tool" && git push

3) لو ظهرت "main -> main" في آخر سطر، التحديث نجح ونُشر.

ملحوظة: بعد ما ينشر هذا التحديث (دقيقة أو دقيقتين)، هستخدم أنا نفس
صندوق الرفع ده عشان أعيد رفع الملفات الخمسة بتاعة 4A/4B (اللي صلحت
أسماء طلابها) عشان ياخدوا درجاتهم، وأبعتلك تقرير نهائي.
