باتش إضافي (v4) فوق اللي طبقته خلاص (v3) — مش من الأول
===========================================================

مهم جدًا: إنت طبقت باتش v3 خلاص ورفعته على GitHub بنجاح (شفت ده في
الـ Terminal بتاعك). الملف ده (skills-fix-v4-ONLY.patch) هو الفرق
الإضافي بس فوق اللي عندك دلوقتي — مش الباتش الكامل من الأول. **لو
حاولت تطبق ملف اسمه skills-fix-v4.patch (من غير "ONLY")، مش هيشتغل
وهيديك error، لأنه مبني على نسخة قبل v3.** استخدم بس الملف اللي اسمه
فيه "ONLY" في الزيب ده.

الجديد في الباتش ده (فوق اللي عندك خلاص):
--------------------------------------------
1. عرض الجملة الأصلية من NWEA تحت كل مهارة (مش بس اسم المهارة
   المختصر) — لو المهارة جايه من الـ Learning Continuum.
2. تحسين وقائي لاختيار أقرب RIT band لو حصلت فجوة في ملف الـ
   continuum مستقبلاً (الملف الحالي مفيهوش فجوات من الأساس، فده تحسين
   للمستقبل بس).
3. تصليح الحالة النادرة: لما المعلم يضيف منطقة يدوي لخطة اتبعتت خلاص،
   بقت بتاخد نفس نظام الـ٣٠-٥٠ سؤال + التوقف عند الإتقان.

التحقق
======
طبّقت نفس الباتش ده بنفسي على نسخة فيها v3 مطبق بالظبط (زي اللي عندك
دلوقتي)، وطلعت مطابقة 100% للنسخة النهائية اللي عندي واتأكد منها
بـ tsc وكل الاختبارات. مفيش أي مفاجآت.

خطوات التطبيق
==============

1) افتح Terminal وروح لمجلد المشروع (المفروض يكون فيه v3 مطبق
   ومرفوع خلاص):

   git status
   (تأكد إنه يقول "nothing to commit, working tree clean" وإنك على
   آخر commit اللي رفعته)

2) فك ملف الـ zip ده في مجلد المشروع.

3) جرب الباتش قبل التطبيق (اختياري):

   git apply --check skills-fix-v4-ONLY.patch

4) طبّق الباتش:

   git apply skills-fix-v4-ONLY.patch

5) سجل ورفع:

   git add -A
   git commit -m "MAP plan: show the NWEA statement text per skill, a more robust nearest-band lookup, and extend the real 30-50 adaptive/mastery-stop rule to the manual add-area path"
   git push
