# Teacher Curriculum page (Update 16)

The page (`/admin/curriculum-map`, teacher view) now shows only what helps the teacher act.

## Kept
- Grade → Unit (tabs) → Text Set / Selection (title, shared read) → sections (Concept Vocabulary, Analyze Craft and Structure, Respond to Reading, ReadMaster article).
- For each section: **⭐ Assign**, **👀 Preview**, and one status label for the chosen class: *Not assigned* · *⏳ x/y done* · *✅ Finished* · *🆘 Needs help* (someone is late).
- Unit buttons: 🗂️ Plan this unit · 🔤 Grammar · 🎮 Games. Class chips (“Status for 4A”) when the teacher has several classes in the grade.

## Removed from the teacher view (still available to admins)
- Question counts per place and level, “adaptive” badges and the 🛟/🚀 ladder wording, the place IDs / tags, the coverage line, “teacher-scored” and “waiting” counts, the ➕ Add question button.

## Behind “Details” (per section)
- The book's skill names, the number of questions per level, ☆ Choose single questions.

## Assign window
- “Adaptive (🛟 → Below → On → Above → 🚀)” → **🤖 Automatic**; “Each at their level” → **✋ Manual (the levels I set on the Levels board)**.
