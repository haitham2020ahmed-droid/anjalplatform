تعليمات تنفيذ هذا التحديث (skillplan_lessons_sync_v1)
========================================================

ده التحديث بيعمل حاجتين:
1) يخلي اسم الوحدة واسم كل درس في صفحة "Skill plan" (داخل Curriculum Map) يتجابوا دايمًا من
   نفس مصدر "Lessons" مباشرة - عشان المشكلة اللي حصلت مع "Lost Island" متتكررش تاني أبدًا.
2) سكريبت جديد (اختياري، تشغّله براحتك لما تحب) يلاقي الدروس القديمة الباقية من نسخة أقدم من
   المنهج (زي "Scout's Honor" و"Jabberwocky...") ويقدر يخفيها من العرض - من غير ما يمسح أي
   مهارة أو سؤال أو درجة طالب خالص، وقابل للتراجع عنه بالكامل.

الخطوات على جهازك (Mac):
------------------------

1) فك ضغط الملف ده في مكان مؤقت.

2) افتح Terminal، وروح لمجلد المشروع بتاعك (anjalplatform)، مثال:
   cd ~/anjalplatform

3) انسخ الملفات دي فوق الموجودة عندك (كل ملف في نفس المكان بالظبط):
   - src/server/curriculum-map/map-pdf.ts
   - src/server/curriculum-map/skill-plan.ts
   - scripts/db/cleanup-stale-lessons.ts   (ملف جديد)
   - package.json

   لو مش فاهم إزاي تنسخهم، قولي وهوريك خطوة بخطوة زي المرات اللي فاتت.

4) اعمل commit و push زي المعتاد:
   git add -A
   git commit -m "Skill plan: unit/lesson names always sync from Lessons tab; add stale-lesson cleanup script"
   git push

5) اعمل Manual Deploy من لوحة Render زي العادة.

بعد الـ Deploy
---------------
- افتح "Skill plan" في Curriculum Map وتأكد إن الأسامي بقت صح ومطابقة لـ "Lessons".

الخطوة الاختيارية (تنظيف الدروس القديمة) - اعملها بس لو عايز:
--------------------------------------------------------------
أولًا تشغيل تجريبي (قراءة بس، مايغيرش حاجة) على جهازك:

   DATABASE_URL="رابط قاعدة البيانات الحقيقي" npm run db:cleanup-stale-lessons

هيطلعلك تقرير بكل الدروس القديمة اللي لقاها. لو النتيجة طابقت اللي احنا متفقين عليه
(Scout's Honor، The Good Samaritan، Jabberwocky...)، شغّل الأمر ده تاني عشان يخفيهم فعليًا:

   DATABASE_URL="رابط قاعدة البيانات الحقيقي" npm run db:cleanup-stale-lessons -- --apply

ملحوظة: الخطوة دي قابلة للتراجع 100% - مفيش أي مسح نهائي، ومفيش أي تأثير على مهارات
الطلاب أو درجاتهم أو الواجبات المرسلة خالص.
